# AIQUOS

AI 使用能力测评网站，包含学生端、教师端、四种测评、班级管理、平均分排名和测评报告查询。

## 如何打开网站

电脑需安装 Node.js 22 或更新版本（自带 npm）。下载本仓库并解压，或使用 Git 克隆仓库，然后在包含 `package.json` 的项目文件夹中打开终端。

第一次运行先安装依赖：

```sh
npm ci
```

启动网站：

```sh
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

终端显示启动成功后，在浏览器打开：

- 学生端：http://127.0.0.1:5173/
- 教师端：http://127.0.0.1:5173/admin.html

运行时保持终端开启；关闭服务可在终端按 `Ctrl+C`。下次使用只需再次运行启动命令。若 5173 端口已被占用，可换成 5174，并将上面的浏览器地址同步改为 5174。

必须通过本地服务打开网站，不能直接双击 `index.html`。GitHub 仓库页面用于存放源码，目前没有已部署的公共网站地址。

## 账号和数据保存

教师端与学生端共享同一份服务端班级数据。注册账号与测评记录保存在：

- `worker/auth-accounts.json`：账号、密码哈希和会话签名密钥。
- `worker/aiquos-shared-data.json`：班级、作业与测评记录。

这些文件首次运行自动生成，重启服务后仍保留，并有备份文件。它们不上传 GitHub；不要删除，迁移自己的运行数据时需连同备份一起妥善保存。

仓库中的 `worker/initial-cohort.json` 是初始班级模板。别人下载源码后首次运行，可以使用上面列出的初始师生账号。你之后自行注册的新账号与新增记录不会随源码自动传给别人，也不会在不同电脑之间自动同步；所有人访问同一台已部署的服务器，才能共享之后的数据。

## 接入模型服务（可选）

若要使用在线对话、模型评分及模型撰写报告，将 `.env.example` 复制为 `.env.local`，填写自己的服务密钥，再重启网站：

```dotenv
DEEPSEEK_API_KEY=填写你的密钥
ARK_API_KEY=填写你的图片生成服务密钥
```

未配置密钥也可以登录并查看初始班级、成绩和报告；在线模型功能需要有效密钥，部分功能提供离线降级。`.env.local` 仅放在自己的电脑或服务器上，不要上传。

## 功能

- 对话式、客观题、实操和综合测评。
- 教师管理班级与学员、发布作业、维护题库并查看成绩。
- 学生查看班级、按已完成测评平均分计算的排名和测评记录。
- 报告查询显示最新测评对应报告，支持下载带嵌入中文字体的两页 PDF。

## 开发与构建

运行自动测试：

```sh
node --test tests/*.test.mjs
```

构建前端静态资源：

```sh
npx vite build
```

产物位于 `dist/client`。静态资源构建不包含运行中的账号和数据服务，单独使用静态托管不能提供完整的登录与师生数据功能。本地完整体验请使用上面的 `npm run dev`。

`npm run build` 还会调用 Sites 部署打包脚本，需要额外的 `.openai/hosting.json` 托管配置；普通源码下载不含该配置，请使用 `npx vite build`。

正式部署需提供后端服务、配置持久化存储及模型密钥。仅上传 GitHub 不会自动部署网站。

## 项目目录

- `src/`：学生端、教师端界面与共享逻辑。
- `worker/`：认证、班级、测评数据和模型接口。
- `public/`：图片、场景、视频和字体等网站资源。
- `vendor/`：六维评分核心。
- `scripts/`：数据初始化、构建和验证工具。
- `tests/`：自动测试。
- `docs/`：师生账号清单和相关文档。
